# CAD 图纸修改智能识别 Agent —— 设计与落地方案

## 1. 核心思路：分层，不要指望"端到端 AI"

图纸修改识别 = **确定性 diff（占 80% 精度）+ LLM 智能层（占 20% 的理解与表达）**。
纯靠多模态大模型看两张图做 diff 会漏改、会幻觉，不适合工程图纸。正确做法是：

1. 把 CAD 解析成结构化"实体表"（图层、类型、坐标、属性）。
2. 用几何/空间算法精确比对，得到变更集。
3. 让 LLM 对变更集做语义摘要、意图判断，并决定如何在图上圈注。

## 2. 三种 diff 策略对比

| 策略 | 做法 | 优点 | 缺点 | 适用 |
|------|------|------|------|------|
| 实体/矢量级 | 解析实体 → 按几何+属性匹配 → 对比 | 精确、可定位到实体、可生成矢量标注 | 需解析 DWG/DXF，处理块/属性复杂 | **主方案** |
| 几何级 | 仅比坐标/包围盒/拓扑 | 比实体级简单 | 丢属性信息（图层、文字、标注） | 辅助 |
| 栅格级 | 渲染成图 → 像素 diff（OpenCV） | 对任意格式鲁棒、无需解析 | 只能给区域、不认"这是什么"、对线宽/样式敏感 | 兜底/可视化 |

推荐：**矢量级为主 + 栅格级兜底**（当解析失败或格式不支持时）。

## 3. 推荐技术栈

- **解析**：`ezdxf`（Python，处理 DXF）；DWG 先用 **ODA File Converter**（免费）转 DXF，或商用 ODA/Teigha SDK。
- **几何/空间**：`shapely`（2D 几何）、`rtree`（空间索引加速匹配）、`numpy`。
- **栅格兜底**：`OpenCV` / `PIL` / `scikit-image` 做图像 diff。
- **Agent/LLM**：`LangGraph` 或轻量 `function-calling` 循环；LLM 负责摘要与决策。
- **输出**：`ezdxf` 生成带 CHANGES 图层的 DXF；`reportlab`/`weasyprint` 出 PDF；`matplotlib` 出对比图。

## 4. 核心算法步骤

1. **解析与标准化**：提取每个实体的 `(layer, type, geometry, 属性, 包围盒)`，统一坐标系，做容差清洗（如 1e-4 级四舍五入）。
2. **生成稳定 key**：优先用 `handle`；若无稳定 handle，退化为 `(type, layer, 量化几何哈希)` 做候选匹配。
3. **空间候选匹配**：用 RTree 只比对邻近实体，避免 O(n²) 全量。
4. **判定变更**（带容差 ε）：
   - 旧有、新无 → **删除**
   - 新有、旧无 → **新增**
   - 两边都匹配但几何/属性不同 → **修改**（位移超 ε 记为"移动"）
5. **高亮/圈注**：对每个变更实体算包围盒，在 CHANGES 图层画红框/圆圈；新增=绿、删除=红虚线、修改=橙。

## 5. 输出（"圈出修改处"怎么落地）

- **矢量版**：在原图新建 `CHANGES` 图层，叠加标注图元（圈、引线、文字说明），可直接在 CAD 打开。
- **对比图**：左右拼图或叠加半透明，圈出差异区域（PNG）。
- **报告**：变更清单 + 自然语言摘要 + 截图（PDF/HTML）。

## 6. 工程落地关键点

- **坐标对齐**：两版可能平移/缩放，先做全局配准（ICP 或最小二乘对齐关键点）。
- **容差**：给几何与坐标设合理 ε，避免把"浮点抖动"误判为修改。
- **块参照（Block/Insert）**：优先比对块引用位置+块名，必要时展开块内实体。
- **文字/标注变更**：文字内容用字符串比对；尺寸标注用数值比对。
- **性能**：大图先做空间索引与分层（只比关注的图层）。

## 7. 最小可行原型（MVP）路径

1. 取两份 DXF（或用 ODA 转出的 DXF）。
2. `ezdxf` 读取实体 → 构建实体表。
3. RTree + 几何容差做 diff → 变更集。
4. 生成带 CHANGES 图层的 DXF + 一张对比 PNG。
5. 接 LLM：输入变更集 → 输出中文摘要与圈注建议。
