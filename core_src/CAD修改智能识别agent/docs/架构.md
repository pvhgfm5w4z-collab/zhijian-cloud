# 架构说明（cad_diff 引擎 v2）

> 设计原则：**确定性矢量 diff（占 80% 精度） + 可选 LLM 语义层（占 20% 表达）**。
> 纯多模态大模型看两张图做 diff 会漏改、会幻觉，不适合工程图纸；正确做法是
> 先把图纸解析成结构化"实体表"，用几何/空间算法精确比对，再用 LLM 做摘要。

## 管线（一次比对）

```
DWG/DXF ──io_dxf──▶ 清洗修复 ──parser──▶ 实体记录表
                                  │
                          align(配准) ──▶ diff(RTree) ──▶ 变更集
                                                      │
        ┌─────────────────────────────────────────────┤
        ▼                      ▼                       ▼
   highlight(圈注DXF)    render(对比/聚焦PNG)    report(TXT/JSON/PDF/HTML)
                                                  llm(语义摘要)
                                                  raster(像素级兜底,可选)
```

## 分层职责

| 模块 | 职责 | 关键能力 |
|------|------|---------|
| config | 集中所有旋钮 | 容差/配准/图层/块/配色/输出/LLM，一处配置 |
| io_dxf | 读写 | dwg2dxf/ODA 回退；修复 XDATA 空行 + MATERIAL 表损坏；探测 PROXY_ENTITY |
| parser | 解析 | LINE/CIRCLE/ARC/POLY/TEXT/MTEXT/INSERT/DIMENSION/MLeader/LEADER/**HATCH**；**INSERT 块内实体递归展开** |
| align | 配准 | 中位数平移（默认）；线角度直方图估计旋转 + 平移（rigid，自动回退） |
| diff | 比对 | 几何指纹哈希分桶 + RTree 候选 + 贪心一对一；ADDED/DELETED/MODIFIED/MOVED |
| highlight | 高亮 | CHANGES 图层按类型画贴合形状（线→旋转细框、圆、弧、收紧矩形），配置配色 |
| render | 渲染 | 整图对比 + 分簇聚焦放大（批量 LineCollection，12k 实体秒级） |
| raster | 兜底 | 两版渲染成灰度图 → absdiff → 轮廓 → 差异框（任意格式鲁棒） |
| report | 报告 | TXT/JSON/PDF/HTML（内嵌图 + 明细表 + 摘要） |
| llm | 语义 | 规则式中文摘要（离线）或 OpenAI 兼容接口（失败自动回退） |

## 已知局限（诚实标注）

- **PROXY_ENTITY（真·天正自定义对象）**：代理图形缺失时仍可能漏检，需先"去天正化"（AutoCAD 另存 T3 / 天正"图形导出"）。
- **DIMENSION 测量值为估算**：dwg2dxf 不导出 `measurement`，用展开图元最长线段近似，仅供定位。
- **缩放变换**：纯缩放会改变图元几何指纹，刚体配准对"仅旋转+平移"有效；含整体缩放的场景建议先统一比例。
- **MTEXT 格式码 / 引线文字**：转换时部分丢失，已 best-effort 提取并如实标注。

## 性能

- 配准用几何指纹哈希分桶 O(n+m)，渲染用 `LineCollection` 批量绘制。
- 实测 1.2 万实体暖通图：约 **6 秒**（旧版含逐实体 matplotlib 绘制约 60 秒，优化 10×）。
